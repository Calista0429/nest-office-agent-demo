NEST / オフィス予約アーキテクチャ

日本語・英語の座席予約デモ — Implemented local flow & optional cloud target

01 · 自然言語で探す

  • 日本語と英語のルールベース解析
  • 日時・人数・設備・隣接条件を抽出
  • 候補を提示し、ユーザーが予約を確定
  • LLM・外部カレンダーは未接続

02 · 予約を確実に保存

  • 全員分を一つのトランザクションで保存
  • 座席・日付・時間の重複をDBで防止
  • 競合時は元の予約を保ち、代替案を提示
  • 再送しても二重予約にならない仕組み

03 · 小さく、検証しやすく

  • React + esbuild + Node.js + SQLite
  • 予約は永続化、言語設定はブラウザーに保存
  • Worker / D1向けビルドを同梱（未配備）
  • 将来のLLMは解析部分を置き換えて接続可能
